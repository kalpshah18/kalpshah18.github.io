Decisions
if and else choose one of two paths
int marks; cin >> marks; if (marks >= 40) {     cout << "Pass\n"; } else {     cout << "Fail\n"; }
  • The condition is converted to bool: 0 is false, every other value is true.
  • The else branch is optional and runs only when the condition is false.
  • Braces group statements. Use them even for one line.
Operators you will use
==  !=  <  <=  >  >= && (and)  || (or)  ! (not)
SC 428 · Lecture 2 · Decisions
Decisions
An else-if ladder stops at the first true test
Correct: strictest test first
char grade; if (marks >= 90)      grade = 'A'; else if (marks >= 75) grade = 'B'; else if (marks >= 60) grade = 'C'; else if (marks >= 40) grade = 'D'; else                  grade = 'F';
Bug: loosest test first
if (marks >= 40)      grade = 'D'; else if (marks >= 60) grade = 'C'; else if (marks >= 75) grade = 'B'; else if (marks >= 90) grade = 'A'; else                  grade = 'F'; // 95 marks -> 'D'
Conditions are checked top to bottom and only one branch runs, so order the tests from most specific to least specific.

Decisions
switch compares one value against many constants
double a, b; char op; cin >> a >> op >> b; switch (op) {     case '+': cout << a + b; break;     case '-': cout << a - b; break;     case '*': cout << a * b; break;     case '/': cout << a / b; break;     default:  cout << "Unknown operator"; }
  • The value must be an integer type, a char or an enum. A string or a double does not compile.
  • Each case label must be a compile-time constant.
  • break leaves the switch. Without it, execution continues into the next case.
  • default runs when no case matches. It is optional; put it last.

Loops
A for loop has three parts in its header
int sum = 0; for (int i = 1; i <= n; i++) {   // init; condition; update     sum += i; } cout << sum;   // n = 5 prints 15
1 · init
int i = 1 runs once
2 · check
i <= n false: exit
3 · body
sum += i
4 · update
i++, then back to 2
Use for when you know how many times to repeat. The variable i exists only inside the loop.
SC 428 · Lecture 2 · Loops
Loops
while checks first; do-while runs at least once
while: count the digits of n
int n = 1234, digits = 0; while (n > 0) {     n /= 10;     digits++; } // digits == 4
May run zero times. For n = 0 it prints 0 digits: handle that case separately.
do-while: ask until the input is valid
int x; do {     cout << "Enter x > 0: ";     cin >> x; } while (x <= 0);  // note the ;
The body runs before the first check, so x always gets a value.

Loops
break leaves the loop; continue skips to the next round
break: first multiple of 7 in [a, b]
for (int i = a; i <= b; i++) {     if (i % 7 == 0) {         cout << i;         break;  // stop searching     } }
continue: print only odd numbers
for (int i = 1; i <= 9; i++) {     if (i % 2 == 0) continue;     cout << i << ' '; } // 1 3 5 7 9
break exits only the innermost loop it sits in.
continue in a while loop skips the update below it: easy infinite loop.

Practice P2 · Solution
code goes inside main(), with #include <iostream>
Prime check
int n; cin >> n; bool isPrime = (n >= 2);   // 0 and 1 are not prime for (int i = 2; i * i <= n; i++) {     if (n % i == 0) {         isPrime = false;         break;     } } if (isPrime) {     cout << "Prime\n"; } else {     cout << "Not prime\n"; }
How it works
  1. Assume n is prime, unless it is 0 or 1.
  2. Try each i from 2 while i × i ≤ n.
  3. If i divides n, n is not prime; break stops the search.
How fast?
For n = 10^9 the loop runs about 31,623 times instead of 10^9. That is O(√n), explained in the next section.

Big-O
Big-O describes how the work grows with n
≈ 10^8
simple operations per second
A rough budget for a 1-second time limit. Compare it with your algorithm’s step count at the largest n.
1 · Drop constant factors
3n + 5 → O(n)
2 · Keep the fastest-growing term
n² + 100n → O(n²)
3 · Assume the worst case
Searching for a missing value checks all n items
4 · Let the limits choose
n ≤ 10^5 means (10^5)² = 10^10 steps: O(n²) is too slow

SC 428 · Lecture 2 · Big-O · Limits are rough, from the 10^8 rule of thumb
Big-O
Count how often the innermost line runs
for (int i = 0; i < n; i++)     for (int j = 0; j < n; j++)         work();
n × n → O(n²)
for (int i = 0; i < n; i++)     for (int j = i; j < n; j++)         work();
n + (n − 1) + … + 1 = n(n + 1) / 2 → O(n²)
for (int i = n; i > 0; i /= 2)     work();
n, n/2, n/4, … 1: about log₂ n steps → O(log n)
for (int i = 0; i < n; i++) work(); for (int j = 0; j < m; j++) work();
One after the other: add → O(n + m)

Big-O · Fast I/O
Two lines that speed up large input and output
#include <iostream> using namespace std; int main() {     ios::sync_with_stdio(false);     cin.tie(nullptr);     int n;     cin >> n;     int sum = 0;     for (int i = 0; i < n; i++) {         int x;         cin >> x;         sum += x;     }     cout << sum << "\n";     return 0; }
sync_with_stdio(false)
cin and cout stop syncing with C’s scanf and printf. Do not mix the two styles afterwards.
cin.tie(nullptr)
cin no longer flushes cout before every read.
"\n" instead of endl
endl also flushes. One flush per line is slow for 10^5+ lines.

Address of a[i] = start + i × sizeof(int). The computer jumps straight there, so a[i] is O(1).

SC 428 · Lecture 2 · Vectors
Vectors
resize changes the size; reserve only the capacity
vector<int> v = {1, 2, 3}; v.resize(5);        // {1, 2, 3, 0, 0} v.resize(2);        // {1, 2} v.resize(4, 9);     // {1, 2, 9, 9} v.reserve(100);     // size 4, capacity >= 100 v.clear();          // size 0, capacity unchanged
size vs capacity
size = elements in use. capacity = slots already allocated. Always size ≤ capacity.
Which one?
resize(n) before writing v[i]. reserve(n) before n push_backs.
Bug
v.reserve(n); v[0] = 5; is undefined: size is still 0.

After erasing numbers[i], the next number slides into index i and the loop skips it.

vector<int> numbers; int x; cin >> x; while (x != 0) {     numbers.push_back(x);     cin >> x; } cout << numbers.size() << "\n"; while (!numbers.empty()) {     cout << numbers.back() << " ";     numbers.pop_back(); }
How it works

  2. back() is the last number read. pop_back() removes it, so the next back() is the one before.
  3. The loop stops when empty() becomes true.
Last in, first out: this is how a stack works.

Recap
Six things to remember from today
Decisions
Order else-if tests from strictest to loosest. Every switch case needs a break.
Loops
For patterns, ask what row i contains. Nested loops multiply the work.
Big-O
About 10^8 simple steps per second. Let the input size choose the algorithm.
Arrays
Valid indices are 0 to n − 1. Anything outside is undefined behaviour.
Vectors
push_back is cheap; insert and erase in the middle are O(n). Pass by reference.
STL
Ranges run from begin() up to, not including, end().
